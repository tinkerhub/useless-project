## Section: during (nav: "during the hackathon")
title: how the hackathon works
lead: No fixed minute-by-minute schedule — venue-wise programs run their own version of the day.

### block: text
Each venue runs its own program on the day — there's no single national schedule. Your venue host
will walk you through timings, meals, and format when you arrive.

### block: steps
1. Clone the starter repo
   PLACEHOLDER — link to the GitHub repo participants clone. It'll have a short animated intro video
   in it, and instructions for getting set up.
2. Build your journal alongside your project
   As you build, keep a "journal" documenting the process — this lives on a separate branch of the
   same repo, not the project code itself.
3. Push your journal branch
   Pushing to that branch auto-deploys it to your GitHub Pages — so your build log is live as you go,
   not written up after the fact.
4. Link it from your README
   Add the GitHub Pages link for your journal to your project's README so judges and other
   participants can find it.
